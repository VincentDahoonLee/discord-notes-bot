# Discord Notes Bot

Stores notes and mentions with reminders.

## The Problem

I struggled with keeping track of things, and as I use discord a lot, having a bot would help keep me on track of things even when not focused.

## How It Works

Using discord.py and a discord app created through Discord's website, I interact with my account through apps and commands to keep myself up to date. 

## Tech Stack

- **Language:** Python
- **Libraries:** discord.py, python-openenv
- **External tools:** discord.py

## Setup

Step-by-step: how does someone who just cloned your repo get it
running?

Make sure to have python installed. Run in your terminal

```bash
git clone https://github.com/you/your-project
cd your-project
./install.sh   # or whatever
python -m pip install -r requirements.txt
```
to set up the directory. 
Create a discord bot through Discord's website, get its token, and install it to your account.
Then, add an .env file to your directory and add to it:
    BOT_TOKEN= #add bot token here
